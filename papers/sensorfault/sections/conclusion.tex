\section{Limitations and Conclusion}
\label{sec:conclusion}
The pixels judge the prior only where they have stiffness: on blank or specular surfaces, where monocular
depth fails most often, the map can report that a surface is unsupported but cannot correct it. The
coupling is first-order and reaches only as far as a surfel footprint, so a prior that is far off is
outside its range. Both sources read the same images, so their errors are not strictly independent. The
segments come from a frozen feature model; a fault that one segment splits is tested only at the coarser
scale.
