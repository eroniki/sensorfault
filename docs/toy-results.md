# Toy results: scale/shift-fitted statistic (CPU, synthetic Gaussian toy)

Generated by `scripts/toy_power.py`; grid 16x16 (n=256), M=10 samples, 200 clean trials for the null, 80 per fault cell, alpha=0.05, 71 s.
Variants: `known` = oracle covariance and TRUE (a,b), no fit (unattainable bound); `oracle` = oracle covariance, (s,t) fitted robustly; `kernel` = stationary-kernel covariance estimated from the M samples, robust fit; `kernel_nr` = same, non-robust fit; `shrunk` = rank-(M-1) sample covariance shrunk to its diagonal, robust fit.
Faults are in units of the per-pixel total residual sd, applied to the samples (the measurement), 12% area for square/edge. Threshold = empirical 95% quantile of the clean-view null of the *same pipeline* (so the two-parameter fit is inside the null).
